01 / The context

Privacy-preserving computation, on the edge

Fully Homomorphic Encryption (FHE) enables computations to be performed directly on encrypted data, without exposing the underlying plaintext. This can allow computation to be outsourced to an untrusted third party while preserving data confidentiality—for example, in privacy-sensitive applications such as facial recognition.

Why CKKS?

CKKS is an FHE scheme for arithmetic over real and complex numbers. It operates on vectors of complex values and polynomials with integer coefficients modulo Q, with security based on the Ring Learning With Errors (RLWE) problem.

Why the edge?

FHE introduces significant computational overhead on both client and server. Many state-of-the-art solutions target high-performance platforms with dedicated hardware, leaving room for more efficient implementations on resource-constrained edge devices.

02 / Target platform

Orange Pi 4 Pro

The implementation targets an ARM single-board computer, exploring how carefully optimized client-side operations can make CKKS more practical beyond conventional high-performance systems.

03 / Engineering approach

Optimization across the computation pipeline

The project aims to deliver an efficient CKKS client-side implementation for the Orange Pi 4 Pro, alongside an end-to-end framework covering client- and server-side operations (excluding bootstrapping).

Sampling routines

  • AES-CTR for pseudo-random data generation
  • Rejection sampling for uniform and ternary distributions
  • Binomial sampling in place of Gaussian sampling
  • Deterministic sampling in a multi-core context

Vector arithmetic

  • DFT/IDFT with aggressive unrolling and vectorization
  • Multiple merge-stage strategies for generic N
  • Multi-core execution

Polynomial arithmetic

  • Montgomery multiplication
  • Lazy reduction
  • NTT/INTT with similar optimizations of DFT/IDFT
Implementation focus: combine algorithmic choices, vector-level optimization, and multi-core execution to reduce the cost of CKKS operations on an ARM edge platform.
